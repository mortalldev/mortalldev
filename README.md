## 🧑‍💻 About Me

Software engineer from **Tashkent, Uzbekistan** building web products since **2021**. At **TUNE Consulting** I work on large-scale **finance, SaaS, CRM and LMS** platforms — from React/TypeScript frontends to Node.js services.

- 🔭 Currently: Software Engineer at **TUNE Consulting**
- 🌱 Learning: DevOps, CI/CD, Docker and Linux server administration
- 🎯 Goal: growing into a **Senior Software Engineer**
- 🧑‍🏫 Former frontend mentor at *Algoritm* IT Learning Center
- 💬 Ask me about: React, Next.js, TypeScript, state management, frontend architecture
- 📫 Fastest way to reach me: [Telegram](https://t.me/mortal_dev) or [LinkedIn](https://linkedin.com/in/mortalldev)

### ⚙️ How I work

- **Type-safe by default** — TypeScript end to end, typed API contracts, no `any` in shared code
- **Server state ≠ client state** — React Query for data, Redux/Context only where it earns its place
- **Forms that scale** — React Hook Form + schema validation for large finance/CRM forms
- **Ship small, ship often** — feature branches, code review, CI pipelines per environment
- **Readable over clever** — components and modules a new teammate can own in a day
